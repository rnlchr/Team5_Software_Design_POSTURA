Frequently Asked Questions

What is the Posture Analysis System?

The Posture Analysis System is a software application that uses Machine Learning and Convolutional Neural Networks (CNN) to analyze a user's posture from an uploaded image. The system evaluates posture alignment and provides feedback and recommendations to help improve posture.

How does the system analyze posture?

The system processes the uploaded image using a trained CNN model that detects posture alignment and identifies possible posture issues. It then generates analysis results and personalized ergonomic recommendations.

How do I upload an image for analysis?

Users can upload a posture image through the system’s interface or capture an image using their device camera. Once uploaded, the system will automatically begin the posture analysis process.

What type of images should I upload?

For best results, upload a clear image of your full body from the side or front view while standing naturally. Ensure the lighting is good and the body posture is clearly visible.

Can I view my previous posture results?

Yes. The system stores your posture analysis results in a database so you can view your posture history and track improvements over time.

Is my data stored securely?

Yes. The system securely stores posture analysis results in a database and ensures that user information is handled responsibly.

How accurate is the posture analysis?

The system uses a machine learning model trained to detect posture alignment, which provides reliable assessments. However, the results are intended for guidance and awareness, not as a medical diagnosis.

Do I need an account to use the system?

Yes. Users must create an account and log in to upload images, receive posture analysis, and track posture history.

Can the system give recommendations to improve posture?

Yes. After analyzing the image, the system provides personalized ergonomic suggestions and posture improvement tips.

What should I do if the system cannot detect my posture?

Make sure the image is clear, well-lit, and shows your full body posture. Try retaking the photo from a proper angle and upload it again.
