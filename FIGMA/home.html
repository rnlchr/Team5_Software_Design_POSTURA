POSTURA

“Start your day with great posture”

About Project:

This project involves the development of a software-based posture analysis system that utilizes Machine Learning, specifically Convolutional Neural Networks (CNN), to assess user posture from uploaded images. The system analyzes posture alignment, identifies improper posture, and provides personalized ergonomic feedback and recommendations. Additionally, it stores posture analysis results in a database, allowing users to monitor posture history and track improvements over time.
